在网页后台写文章、插入图片和修改个人介绍。

## 进入后台

**[打开文章编辑后台 →](https://app.pagescms.org/)**

使用拥有这个博客的 GitHub 账号 `sleepy-m` 登录，打开 `sleepy-m.github.io`，选择 `main` 分支。

第一次使用时，需要连接 Pages CMS：在 GitHub 授权页面选择 **Only select repositories（只选择指定仓库）**，只勾选 `sleepy-m.github.io`。完成后返回后台。

## 在哪里编辑

- **文章管理**：新建或编辑文章，填写标题、发布日期、分类和标签。正文使用可视化编辑器，支持标题、列表、链接、图片和代码。
- **图片管理**：上传图片，在正文中通过图片按钮插入。
- **关于我**：修改个人介绍。
- **博客设置**：修改博客名称、简介和作者名称。

## 保存后会发生什么

编辑器中可以直接看到文字排版。**在文章管理中保存会提交文章并触发网站更新**；等自动构建完成后刷新博客查看。公开页面的最终外观由当前博客主题决定。

尚未写完的文章请先保存在自己的文档中，准备公开时再保存到文章管理。此版本没有单独的草稿发布开关。
