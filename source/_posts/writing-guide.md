## 创建文章

双击博客目录中的“新建文章.cmd”，输入文章标题。文章保存在 `source/_posts` 中，使用普通 Markdown 编辑器即可修改。

## 标题与列表

用 `## 小标题` 分段，用 `- 内容` 写列表。文章顶部的 `categories` 是分类，`tags` 是标签。

## 代码

在代码前后各写三个反引号，并在开头注明语言：

```python
def hello():
    print("开始记录")
```

## 图片

新建文章时会生成同名资源文件夹。把图片放进该文件夹，例如 `photo.jpg`，在正文中写：

```markdown
![图片说明](photo.jpg)
```

## 预览和发布

双击“本地预览.cmd”，在浏览器打开 http://127.0.0.1:4000 。保存文章后刷新页面查看效果。

确认内容后，双击“发布博客.cmd”。首次发布需要关联 GitHub 仓库，之后推送会触发自动构建。

## 保存内容

文章和图片都在 `source` 文件夹中。`public` 是生成结果，不需要手动编辑。发布前检查正文、图片和草稿是否适合公开。
